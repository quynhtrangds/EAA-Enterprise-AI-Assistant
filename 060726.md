# Tổng kết ngày 06/07/2026

## Phạm vi đã làm

Backend API cho MVP Enterprise AI Assistant dùng MCP với PostgreSQL.

## 1. MCP Gateway

Thư mục:

```text
apps/mcp-gateway
```

Đã hoàn thiện:

- Express API backend.
- MCP Runtime để đăng ký, liệt kê và gọi tools.
- PostgreSQL Connector.
- 6 tools read-only:
  - `search_customer`
  - `get_customer_orders`
  - `get_order_detail`
  - `get_revenue_summary`
  - `get_top_customers`
  - `get_product_sales_summary`
- Validate input bằng Zod.
- Query database bằng SQL `SELECT` và parameterized query.
- Không có raw SQL tool.
- Permission theo role thông qua bảng `tool_permissions`.
- Auth MVP bằng header `x-user`.
- Audit log cho tool call thành công và thất bại.
- API xem audit log chỉ dành cho admin.
- Error response được chuẩn hóa.

API đã có:

```http
GET /health
GET /api/tools
POST /api/tools/call
GET /api/audit-logs
```

## 2. AI Orchestrator

Thư mục:

```text
apps/ai-orchestrator
```

Đã tạo backend service mới:

- Express API backend.
- `MockLLMProvider` để map câu hỏi tiếng Việt sang tool call.
- MCP Gateway client để gọi:
  - `GET /api/tools`
  - `POST /api/tools/call`
- `ChatService` điều phối flow:
