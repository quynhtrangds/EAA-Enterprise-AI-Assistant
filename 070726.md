## 4. Unicode và database seed

Đã xác nhận PostgreSQL đang dùng encoding:

```text
server_encoding = UTF8
client_encoding = UTF8
```

Lỗi tiếng Việt không dấu nằm ở seed data, không phải DB encoding.

Đã cập nhật:

```text
database/schema.sql
database/seed/seed.sql
database/migrations/001_utf8_seed_data.sql
```

Nội dung:

- Thêm `CREATE EXTENSION IF NOT EXISTS unaccent;`.
- Đổi customer/product/role/user display data sang tiếng Việt có dấu.
- Apply migration vào Postgres container đang chạy.
- Sửa `search_customer` trong `apps/mcp-gateway/src/connectors/postgres/tools/index.ts` để search accent-insensitive bằng `unaccent`.

Đã verify:


Nội dung:

## 8. Sửa auth không fallback admin

Đã cập nhật:

```text
apps/mcp-gateway/src/auth/current-user.ts
apps/mcp-gateway/src/errors/app-error.ts
```

Nội dung:

- Bỏ logic fallback mặc định về `admin` khi thiếu header `x-user`.
- Nếu header `x-user` không tồn tại hoặc rỗng sau khi trim, MCP Gateway trả lỗi HTTP 401.
- Mã lỗi trả về là `UNAUTHORIZED`.
- Message trả về:

```text
Bạn phải cung cấp header x-user để đăng nhập
```

JSON lỗi chuẩn:

```json
{
  "success": false,
  "errorCode": "UNAUTHORIZED",
  "message": "Bạn phải cung cấp header x-user để đăng nhập"
}
```
